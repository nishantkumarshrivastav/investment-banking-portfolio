# DCF Valuation Model

## Project Overview

This project demonstrates a practical Discounted Cash Flow (DCF) valuation of a listed company.

The objective is to estimate the intrinsic value of the company based on its expected future free cash flows.

## Valuation Framework

Revenue Forecast
↓
EBITDA Forecast
↓
EBIT
↓
Tax
↓
Free Cash Flow
↓
WACC
↓
Terminal Value
↓
Enterprise Value
↓
Equity Value
↓
Implied Share Price

## Key Components

* Historical Financial Analysis
* Revenue Forecasting
* EBITDA Forecasting
* Free Cash Flow
* WACC Calculation
* Terminal Value
* Enterprise Value
* Equity Value
* Sensitivity Analysis
